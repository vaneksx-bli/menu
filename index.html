Как подключить (один раз; регистрация только у одного из семьи)
  1. gist.github.com → файл menu.json, содержимое {} → Create secret gist → скопировать ID (хвост ссылки после последнего «/»).
  2. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → галка только gist → создать → скопировать токен.
  3. Вставить оба значения выше → «Сохранить и подключить» → «⬆ Отправить».
  4. На втором устройстве открыть ссылку Pages → те же значения → «Сохранить и подключить» → «⬇ Загрузить».
  5. «🔗 Ссылка для семьи» — ссылка со встроенным кодом доступа для второго супруга.
